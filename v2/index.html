Built with Claude Code skills

Version 2 of this board was redesigned and checked using project skills stored in the repository under .claude/skills. The classic board is still available.

  • frontend-design Dark blue and gray theme, a board summary with live counts, and urgency labels such as "3 days overdue" and "Due in 2 days" on every card.
  • ui-ux-pro-max Sorting, search, a "+" button on each column and keyboard shortcuts. Every text colour passes contrast checks, and buttons are at least 44 px on phones.
  • cybersecurity-analyst Threat model and XSS test. Added a content security policy that limits network calls to the email service, plus a spam-trap field.
  • publish-github Publishing. GitHub Pages serves v2 next to the classic board, with automated checks before each deploy.
